# Changelog

Record customer-visible features and fixes here. Add an entry with every future change.

## 2026-10-15

- Added ten sample gadgets and two TDP store locations.
- Added price sorting, bookmarks, Favourites, Account, Orders, History, and Customer care sections.
- Demo checkout now creates an in-memory order. No payment is taken.
## 2026-10-15 (appearance)

- Added a blue-to-deep-navy gradient banner, translucent surfaces, and coordinated light/dark palettes across customer screens.
- Added a header toggle to switch between light and dark mode.
- Updated the interface typography to a formal, platform-friendly font stack.


## 2026-10-15 (shop-first home)

- Replaced product recommendations on Home with a featured shop promotion and cards for each TDP location.
- Grouped product search, store, category, and sort controls into one Shop filter panel.


## 2026-10-16 (store cards)

- Changed Home's shop list into rectangular cards in a responsive two-column grid, showing each shop's name, location, and product count.


## 2026-10-16 (code organization)

- Split catalog data, reusable product/filter components, shared typography, and theme styles into separate beginner-friendly JavaScript modules.
- Kept App.js focused on app state, actions, and choosing which screen to show.
